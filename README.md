# 📚 Learning Lode: Student Performance Tracker

**Learning Lode** is a full-stack academic tracking platform designed to bridge the gap between educational administration and classroom performance. Built with a deep understanding of institutional grading workflows, it helps teachers and administrators manage student records, track academic progress, and align reporting with official educational frameworks.

---

## 🎯 Purpose & Vision

In many educational settings, tracking student performance efficiently remains an administrative bottleneck. Learning Lode was conceptualized to provide a streamlined, responsive, and intuitive digital solution that simplifies grade recording, performance monitoring, and data organization for educators—allowing them to spend less time wrestling with paperwork and more time supporting student success.

---

## ✨ Key Features

*   **GES Grading Alignment:** Configured to integrate with standard educational grading structures (such as the official Ghana Education Service framework).
*   **Student Performance Analytics:** Centralized dashboards for monitoring individual and class-wide academic trends.
*   **Secure Role-Based Access:** Built with secure authentication to ensure student data privacy and proper administrative controls.
*   **Responsive & Clean Interface:** Designed with a distraction-free, modern layout optimized for both desktop and mobile use by busy educators.

---

## 🛠️ Tech Stack & Architecture

*   **Frontend:** React, TypeScript, Vite, Tailwind CSS
*   **Backend & Database:** Firebase Authentication & Cloud Firestore (for real-time data persistence and secure auth)
*   **State & Routing:** Modern component-driven architecture with clean state management

## 🚀 Getting Started Locally

If you want to run or inspect this project locally, follow these steps:

Install Dependencies:
npm install

Configure Environment Variables:
Create a ⁠.env⁠ file in the root directory and add your Firebase configuration credentials:
VITE_FIREBASE_API_KEY=your_api_key
VITE_FIREBASE_AUTH_DOMAIN=your_auth_domain
VITE_FIREBASE_PROJECT_ID=your_project_id

Run the development server:
npm run dev
